🛠️ Common Issues and Solutions

Problem: "The application won't run or crashes on startup."
Solution: Make sure you have the latest version of your graphics drivers and that Windows is fully up-to-date. Also, try running the launcher as administrator.
Problem: "I can't find my games or mods."
Solution: The launcher automatically detects your Project Zomboid installation. If it can't find it, use the "Set Game Folder" option in Settings and manually navigate to your game directory.
Problem: "The Java loader isn't working properly."
Solution: Ensure you have a 64-bit Java runtime installed (version 17 or later recommended). You can download Java from the official Oracle website.
